## Interim failures (all fixed before the final runs)

None of these needed a change to an earlier gate's code or test.

1. **API tests, first run: 13 / 17.** All four were in my tests.
   - A secret check matched Shahid's phone number (`0201`).
   - Larkspur (a developer) has payroll in its preset, so "no other organisation" became "no other society".
   - HR recorded 6 days for Tariq, not 3.
   - The loan test seeded payroll after the loan was approved.
2. **Full unit suite, first run: 1 failure.** `platform.test.ts` compares the HQ-created Al-Noor's modules with the workspace's. The storyline was given `sel('payroll')`, as S.2a did for `hr`; the assertion is unchanged.
3. **S.2b E2E, first run: 7 / 13.**
   - **Test-side:**
     - references carry word joiners, so they are now checked as data;
     - plain fields carry their test id on the input itself.
   - **Real layout defects at 320 px / 200 %:**
     - money values and "Not available" clipped in the dashboard tiles;
     - references broken at hyphens;
     - a long Urdu button label off the screen.
   - All fixed (report §2.7).
4. **S.2b E2E, second run: 11 / 13.** Two more real defects at 320 px / 200 %:
   - the English page title "Disbursement status" was wider than the screen; it became "Pay instructions";
   - the Urdu journal table scrolled off the side; it is now a list.
5. **S.2b E2E, third run:** **13 / 13**.
6. **Developer-case test, first run.** It asserted `permission_missing` but saw `module_not_licensed`: the same test had withdrawn payroll for the whole page. It was split into its own test, which passes.
