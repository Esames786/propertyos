## E.13 hooks needed at integration (not on this base)

- **Record providers** (`registry.ts PROVIDERS`): `supplier` (`sup_…` → SUP-002), `supplier_bill` (`sbl_…` → SUP-004), `supplier_payment` (`spi_…` → SUP-006 `?record=`), `expense` (`exp_…` → EXP-003), `budget` (`bud_…` → EXP-008), `petty_cash_float` (`pcf_…` → EXP-005). - **Tasks** (`tasks.ts`): bills awaiting approval (for `supplier_bill.approve`, never the maker), instructions awaiting approval, expenses and claims awaiting a decision (never the maker or claimant), budget versions awaiting approval, petty-cash counts awaiting a witness, top-ups awaiting approval.
- **Activity** (`activity.ts`): each record's `history` (`PayablesEvent`), supplier activity projected with `projectHistory`.
